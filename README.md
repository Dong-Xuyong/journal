# Journal

A private journal for day, week, month, quarter, and year progress.

Live: https://dong-xuyong.github.io/journal/

Entries and the quote of the day live in Dong-Xuyong/progress-sync, file journal.json. The quote is `quotes["YYYY-MM-DD"].text`.

The page auto-loads that file on open, on focus, and every 60 seconds.

Save still asks twice before it writes.

CONTRACT.md is the writer spec for updating journal.json.
